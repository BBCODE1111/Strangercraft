# 遊戲說明

這是一個單純的《怪奇物語》粉絲作品，簡化並改編了許多劇情流程，沒有追求高度還原。製作它的初衷，只是希望帶來沉浸的體驗，讓你感受走進顛倒世界的氣氛。

## 故事與目標

一次地下室裡的 D&D 聚會，成為 Hawkins 冒險的起點。你和朋友將調查 Byers 家的異常、深入森林找回 Will，在被根系侵蝕的顛倒世界尋找返回現實的裂口，最後與 Eleven 一起迎戰學校裡的魔神。

遊戲支援 1–6 人，劇情進度由全隊共用。開始前先等朋友到齊，再由房主輸入 `/hawkins start`。

## 探索與推進劇情

1. 從地下室出發，到 Byers 家查看供電線索。
2. 沿森林中的低燈尋找 Will。右鍵他並靠近、看著他 5 秒，完成救援。
3. 從附近工具桶取得保險絲，帶回 Byers 家客廳，右鍵電源箱。
4. 聖誕燈會自動顯示 RUN。前往 Hawkins 中學西北側科學教室，尋找流動的紅色裂口。
5. 一位可行動隊友穿過裂口，整隊都會進入現實學校，包括倒地或觀戰中的同伴。
6. 在學校裡利用道具和地形牽制魔神，掩護 Eleven 充能與施法。

迷路或不確定下一步時，右鍵對講機查看目前目標。

## 魔神如何追蹤你

魔神會聽見走路、奔跑與道具聲響，並調查聲音的位置；近距離正面視線也會讓牠追擊。

牠比正常衝刺更快，單靠直線跑步很難脫逃。利用轉角、家具和牆壁切斷視線，再進入窄通道；也可以先投出誘餌，將注意力引開。按住 Shift 蹲下能減少腳步聲，但仍要避開牠的正面視線。

| 對講機 | 右鍵看目前任務；R 收起；Page Up / Page Down 翻頁 |
| 空罐 | 右鍵投擲，製造聲響誘導魔神 |

| 火把 | 使用時消耗，提供短暫護身 |

對講機收起按鍵可在控制設定中修改。工具桶能提供探索與戰鬥用的道具。

## 倒地、救援與觀戰

- 一般難度、滿血無防具且未治療時，第一次有效受擊剩 6.5 顆心、第二次剩 3 顆心，第三次倒地；保留約兩秒共用受擊保護。
- 同伴有 **60 秒** 可以救援：右鍵倒地者，靠近並看著他 **5 秒**。
- 移開、受傷或蹲下會中斷救援；先引開魔神，再救人會更容易。
- 逾時會被囚禁在森林樹上。隊友仍可到你的身體旁右鍵救援。
- 觀戰時，**1–6** 切換隊友視角，**0** 自由漂浮。
- 決戰中的囚禁者留在決戰觀戰；全隊無法行動時，10 秒後重試本章。

## 學校決戰

魔神生命、Eleven 生命與 Eleven 能量會顯示在畫面上。

Eleven 開場需要到學校後方的鹽水池充能。隊友應利用聲音、道具與走位牽制魔神，讓她取得施法空間。能量用盡後，她會回鹽水池，約需 15 秒補充；充能期間尤其需要掩護。

魔神需要承受六次有效超能力命中，分成兩輪充能。每次受擊都會被拋飛，撞牆或落地後才恢復。趁這個空檔調整位置、補充誘餌與救人。

如果 Eleven 在戰鬥中死亡，5 秒後只重試決戰。完成第一幕後，可選擇全隊重玩、留在學校或離開；留在學校後，右鍵對講機能再次開啟結局選單。

## 重玩與保留進度

`/hawkins restart` 會重設目前世界的全隊劇情。想保留這一局時，退出後從遊戲包另存一個乾淨世界。

每場最多保留六個玩家身分；換一整批朋友時，請建立新的乾淨世界。
